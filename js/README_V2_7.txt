BDHS V2.7 - AUTO SYNC + EXCEL ARCHIVE

1. Ghi nhớ đăng nhập theo thiết bị.
2. Mất mạng vẫn lưu dữ liệu cục bộ bình thường.
3. Khi có mạng, dữ liệu tự đồng bộ sau khoảng 5 giây.
4. Mở app sẽ tự kiểm tra Cloud và tải dữ liệu mới hơn.
5. Nếu có xung đột, app không tự ghi đè mà giữ dữ liệu trên máy và cảnh báo.
6. Cài đặt chỉ còn nút Đồng bộ ngay, Đổi mật khẩu và Đăng xuất.
7. Báo cáo tháng có nút Xuất Excel tháng. File xuất theo chuẩn Excel XML, gồm 5 sheet:
   - 01_Tổng hợp
   - 02_Doanh thu
   - 03_Chi vốn
   - 04_Đơn MTF
   - 05_Kiểm kê
8. Data Core và công thức nghiệp vụ không thay đổi.

Lưu ý: file Excel xuất có đuôi .xml, mở trực tiếp bằng Microsoft Excel. Có thể dùng Save As để lưu lại thành .xlsx.

V2.7.1 XLSX TEMPLATE EXPORT
- Xuất trực tiếp file .xlsx thật.
- Dùng file BDHS_Excel_Thang_Official_Template.xlsx làm mẫu mặc định.
- Có thể thay mẫu tại Cài đặt > Mẫu Excel tháng; mẫu tùy chỉnh lưu trong IndexedDB trên thiết bị.
- Không cần sửa code khi chỉ đổi màu, font, viền hoặc bố cục.
- Bắt buộc giữ nguyên 6 tên sheet và các ô/vùng dữ liệu chuẩn.
